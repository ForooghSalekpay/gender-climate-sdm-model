# gender-climate-sdm-model
System dynamics model files accompanying the manuscript: 
"A system-dynamics study of the impact of gender equality on carbon emissions"


## Software

Models were developed using Vensim Professional 10.4.


## Model files

- Case 1: Basic model
- Case 2: Dynamic women's shares
- Case 3: Critical-mass mechanism
- Case 4: Carbon-budget feedback
- Case 5: Income feedback
